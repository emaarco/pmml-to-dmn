# Security Policy

## Supported versions

This project is in active early development. Security fixes are applied to the `master` branch.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report them privately via GitHub's
[security advisories](https://github.com/emaarco/pmml-to-dmn/security/advisories/new) or by email to
**marco.schaeck@miragon.io**. You will receive an acknowledgement as soon as possible, and we will
work with you to understand and address the issue.

Note that this tool parses XML: only convert PMML files from sources you trust.
